Backend Setup

For real centralized storage on Vercel, add these Environment Variables:

  • ADMIN_TOKEN - private password for this admin panel API calls
  • GITHUB_TOKEN - GitHub token with repo issue permission
  • GITHUB_REPO - for example: 13857368sarf-cpu/waverider-power-b2b-site

After setting them, redeploy Vercel. Form submissions will become private GitHub Issues labeled inquiry, and this page can read them with your admin token.
